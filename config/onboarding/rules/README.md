# 가입 규칙 문서

이 폴더에 실제 서버 규칙을 UTF-8 `.md` 또는 `.txt` 파일로 저장하세요.
파일 하나가 가입 화면의 규칙 한 페이지가 되며, 각 페이지에서 동의해야 다음 페이지로 넘어갑니다.

- 파일명 순서대로 표시합니다. `01-기본규칙.md`, `02-게임규칙.md`처럼 번호를 두 자리로 붙이세요.
- 확장자를 제외한 파일명이 화면의 제목입니다. 본문은 Discord Markdown으로 표시됩니다.
- 파일당 본문은 최대 3500자이며 빈 문서는 사용할 수 없습니다.
- `README.md`, `*.example.md`, `*.example.txt`, 하위 폴더는 읽지 않습니다.
- `01-기본규칙.example.md`는 작성 틀일 뿐이며 실제 가입 규칙으로 표시되지 않습니다. 복사한 뒤 `.example`을 제거하고 서버 규칙을 입력하세요.
- 실제 문서가 없으면 기존 `/가입관리 설정`의 `규칙내용`을 한 페이지로 사용합니다. 둘 다 없으면 가입 설정·진행 시 오류를 안내합니다.
- 규칙 문서의 제목·내용·순서가 바뀌면 버전이 바뀌어 이전 동의를 새 문서에 재사용하지 않습니다.

이 폴더의 실제 규칙 파일도 배포 대상입니다. 변경 후 봇 서버에 파일을 반영하세요.
