## 목표 (한 문장)
`src/services/ForumPostManager.js`(87건)와 `src/services/MappingService.js`(64건)의 모든 `console.*` 호출을 `logger`로 치환하되 **동작(제어 흐름·반환값)은 그대로** 유지한다.

## 범위
- 수정: 위 2개 파일만. 다른 `src/**` 파일 수정 금지.
- 건드리지 말 것: 생성자 시그니처(I-01 — DI 파라미터 이름·순서 변경 금지), 메서드 시그니처, try/catch 구조.

## 치환 규칙
- `import { logger } from '../config/logger-termux.js';` 를 기존 import 블록 끝에 추가 (이미 있으면 생략).
- 매핑: `console.log`→`logger.info`, `console.info`→`logger.info`, `console.warn`→`logger.warn`, `console.error`→`logger.error`, `console.debug`→`logger.debug`.
- **시그니처**: `logger.<level>(message: string, meta?: object)`. 두 번째 인자는 반드시 **객체**여야 한다.
  - `console.error('msg:', err)` → `logger.error('msg', { error: err.message, stack: err.stack })`
  - `console.warn('msg:', err.message)` → `logger.warn('msg', { error: err.message })`
  - `console.log('msg', someObj)` → `logger.info('msg', { value: someObj })` (객체가 아니면 `{ value }`로 감쌈)
  - 템플릿 리터럴 단독 메시지는 그대로 첫 인자로.
  - 메시지 끝의 `:` 는 제거.
- 기존 `[ForumPostManager]` / `[MappingService]` 접두 유지 (`src/services/InactivePostChecker.js` 스타일 참고).
- 로그 라인 삭제·추가·레벨 변경 금지 (1:1 치환만).

## 단계
1. 각 파일에서 `grep -n "console\." <file>` 로 목록 확보.
2. 치환.
3. `npm run lint` — 해당 2파일에서 `no-console` 경고 0 확인: `npx eslint src/services/ForumPostManager.js src/services/MappingService.js`
4. `node -e "import('./src/services/ForumPostManager.js').then(()=>console.log('ok'))"` 및 MappingService 동일하게 모듈 로드 확인.
5. `npm test` 통과.
