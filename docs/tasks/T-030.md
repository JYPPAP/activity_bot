- **로직 수정 금지.** 메서드 본문은 잘라내어 옮기기만 한다(이동 + `this.x` 참조 조정). 조건·문구·순서를 바꾸지 않는다.

- 외부에서 호출되는 메서드 3개는 Facade에 남긴다(위임 형태): `routeButtonInteraction`, `handleRoleTagButtons`, `handlePreMembersSelectMenu` — 호출처: `grep -rnE "buttonHandler\.\w+\(" src | grep -v ButtonHandler.js`.
- `src/ui/ButtonHandler.js` 외 `src/**` 수정 금지 (신규 파일 생성은 `src/ui/buttons/` 아래만).
