## 목표 (한 문장)
Slack 알림 코드·설정·의존성을 모두 제거하고, `logger.*`는 Errsole 기록만 수행한다.

## 범위 (사용자가 §6 "인간 승인 필요" 항목인 `.env.example`, `ecosystem*.cjs` 수정을 이 태스크에 한해 승인함)
- `src/config/logger-termux.js`
  - `sendSlackAlert` 함수 전체 삭제 (약 230~310행)
  - `logger.debug/info/warn/error/alert` 등에서 `sendSlackAlert(...)` 호출 줄 삭제 — **errsole 호출은 유지**
  - 시작 로그 중 `ENABLE_SLACK_ALERTS`, `SLACK_WEBHOOK_URL`, `SLACK_CHANNEL`, `SLACK_MIN_LEVEL` 출력 줄과 "Slack 알림 활성화/비활성화" 분기 삭제. 주석의 "(Slack 알림 포함)" 문구도 제거
  - `import axios` 삭제 (이 파일 외 axios 사용처 없음 — 확인됨)
- `src/config/env.js`: `ENABLE_SLACK_ALERTS`, `SLACK_WEBHOOK_URL`, `SLACK_CHANNEL`, `SLACK_MIN_LEVEL` 4개 키와 주석 삭제
- `package.json`: `scripts.slack` 삭제, `dependencies.axios` 삭제 (`npm uninstall axios` — 로컬 제거, 네트워크 불필요). `overrides`의 `follow-redirects`, `form-data`는 axios 전용 취약점 override였을 가능성이 높으니 `npm ls follow-redirects form-data`로 다른 사용처가 없으면 함께 삭제
- `.env.example`: 38~42행 Slack 블록 삭제
- `ecosystem-termux.config.cjs`: `// Slack 알림 설정` 주석과 `ENABLE_SLACK_ALERTS: 'true'` 삭제
- `docs/13-playbooks.md` 113행 Slack 체크리스트 항목 삭제, `docs/ARCHITECTURE.md` 145행 Slack 환경변수 줄 삭제
- **건드리지 말 것**: 위 목록 외 파일. `logger` 객체의 export 형태·메서드 이름은 불변(다른 파일에서 `logger.info(msg, meta)` 시그니처로 사용 중).
