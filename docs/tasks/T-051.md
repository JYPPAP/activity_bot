# T-051 전역 에러 핸들러 보강: Discord client / pg Pool 'error' 리스너

상태: done
계획: docs/IMPROVEMENT_PLAN.md §T-051

## 목표 (한 문장)
Discord `Client`와 pg `Pool`이 내는 `'error'` 이벤트에 리스너가 없어 프로세스가 죽는 경로를 막고, 로그로 남기게 한다 (Termux 네트워크 단절 시 재시작 폭풍 방지).

## 측정 (2026-09-22, Claude)
- `process.on('uncaughtException'/'unhandledRejection')`: `src/config/logger-termux.js:151,183`에 있음 — 유지.
- `client.on('error' | 'shardError' | 'warn')`: **없음** (`src/bot.js`, `src/services/EventManager.js` 확인). Node EventEmitter 규칙상 리스너 없는 `'error'` 이벤트는 throw → uncaughtException → PM2 재시작.
- `pool.on('error')`: **없음** (`src/services/DatabaseManager.js:43-50`). pg 문서: idle client 에러는 Pool `'error'` 이벤트로 나오며 리스너 없으면 프로세스 크래시.
- graceful shutdown: `src/index.js:37-38` SIGTERM/SIGINT 있음 — 유지.

## 범위 (추가 전용, 기존 줄 수정 금지)
1. `src/bot.js`: `this.client = new Client({...})` 직후(또는 이벤트 등록 지점)에 추가:
   ```js
   this.client.on('error', (error) => logger.error('[Discord] client error', { error: error.message, stack: error.stack }));
   this.client.on('shardError', (error, shardId) => logger.error('[Discord] shard error', { shardId, error: error.message, stack: error.stack }));
   this.client.on('warn', (message) => logger.warn('[Discord] client warn', { message }));
   ```
   `logger` import가 없으면 `import { logger } from './config/logger-termux.js';` 추가. `EventManager`가 client.on을 래핑하고 있으면(`EventManager.js:28`) 그 경로를 써도 되나, **'error'는 반드시 등록**되게 하고 어느 쪽을 택했는지 보고.
2. `src/services/DatabaseManager.js`: `this.pool = new Pool({...});` 직후에 추가:
   ```js
   this.pool.on('error', (error, client) => {
     logger.error('[DatabaseManager] idle client error', { error: error.message, stack: error.stack });
   });
   ```
   (`client` 인자를 안 쓰면 `_client`로 — `no-unused-vars` `argsIgnorePattern: '^_'`.)
3. 그 외 파일 수정 금지. 로그 레벨·메시지 형식은 `logger.<level>(message, meta)` 규칙(I-09).

## 테스트
- `tests/services/DatabaseManager.test.js`에 1개 추가: `initialize()`는 실 DB라 호출 불가 → 대신 `Pool` 생성 직후 리스너 등록 로직이 별도 메서드로 분리 가능하면(예: `attachPoolListeners(pool)`) 그 메서드를 `pool = { on: vi.fn() }`로 호출해 `on('error', fn)`이 등록되는지 검증. 분리하지 않으면 테스트 생략하고 사유 보고.
- `src/bot.js`는 실제 Client 생성이라 테스트 생략.
