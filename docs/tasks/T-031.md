생성자에 `this.RETRY_CONFIG`, `this.modalStats`, `this.responseTimeSum`, `this.submissionHistory` 가 있고 여러 메서드가 이를 읽고 쓴다. **상태의 소유자를 하나로 정하고** 나머지는 그 소유자를 통해 접근한다:
- `ModalStatistics`(신규 클래스)가 `modalStats`, `responseTimeSum`, `submissionHistory`를 **소유**. Facade는 `this.stats = new ModalStatistics()` 로 보관.
- 다른 모듈/Facade에서 `this.modalStats.totalSubmissions++` 같은 직접 접근이 있으면 `this.parent.stats.modalStats.totalSubmissions++` 식으로 **같은 객체를 가리키게** 바꾼다 (복사 금지 — 참조가 끊기면 통계가 갈라진다).
