## ⚠️ 의미 차이 주의 (가장 중요)
`safe*`는 실패 시 **throw 하지 않고 `null`을 반환**한다. 따라서 직접 호출을 감싸던 `try { await interaction.reply() } catch (e) { ... }`에서 catch 블록이 **의미 있는 동작**(폴백 응답, 상태 롤백, return 등)을 하면 교체 후 그 경로가 죽는다.
- 각 22건마다 주변 try/catch를 확인하고: catch가 단순 로깅뿐이면 그대로 교체. catch가 흐름을 바꾸면 `const result = await SafeInteraction.safeX(...); if (result === null) { <기존 catch 로직> }` 형태로 보존.
- 판단이 애매한 케이스는 교체하지 말고 파일:줄과 이유를 마지막 메시지에 보고.
- `deferReply` 후 `editReply`를 쓰는 패턴은 `safeDeferReply`로 바꿔도 이후 `editReply`는 그대로 둔다.
