## 목표 (한 문장)
실제 PostgreSQL 없이 `DatabaseManager.query/transaction`의 계약(BEGIN/COMMIT/ROLLBACK/release 순서)과 `ForumRepository` 핵심 메서드의 SQL 호출 패턴을 mock으로 고정해, Phase 3 분할(T-033) 시 회귀를 잡는다.

## 범위
- 신규: `tests/services/DatabaseManager.test.js`, `tests/repositories/ForumRepository.test.js`
- **건드리지 말 것**: `src/**` 일체. 실패하면 `it.todo` + 보고.
- `pg`는 import하지 않는다. `DatabaseManager` 인스턴스를 만든 뒤 `dm.pool = { query: vi.fn(), connect: vi.fn() }` 로 주입(생성자는 pool=null로 시작 — `src/services/DatabaseManager.js:14-25` 확인). `initialize()`는 호출 금지(실 DB 접속).
- `ForumRepository`는 `new ForumRepository(fakeDbManager)` 로 생성. `fakeDbManager = { query: vi.fn(), transaction: vi.fn() }`.
- logger는 `tests/setup.js`에서 이미 mock됨.

## 테스트 케이스
`DatabaseManager` (`src/services/DatabaseManager.js:95-145` 먼저 읽기):
- `query()`: pool이 null이면 throw('데이터베이스가 초기화되지 않았습니다.'); pool.query 결과를 그대로 반환하고 (text, params) 그대로 전달; pool.query가 throw하면 재throw.
- `transaction()`: 성공 시 client.query 호출 순서가 정확히 `['BEGIN', <callback 쿼리들>, 'COMMIT']` 이고 `release()` 1회; callback이 throw하면 `ROLLBACK` 호출 후 같은 에러 재throw, `release()` 여전히 1회; callback 반환값이 그대로 반환됨.
  - client mock: `{ query: vi.fn().mockResolvedValue({rows:[], rowCount:0}), release: vi.fn() }`, `pool.connect.mockResolvedValue(client)`.

`ForumRepository` (각 메서드 본문을 먼저 읽고 실제 SQL 흐름 기준으로 작성):
- `getPostIntegration(voiceChannelId)`: query가 rows 1건 반환 시 그 row(또는 구현이 반환하는 형태)를 반환, 0건이면 null/undefined(구현 확인).
- `createPostIntegration(...)`: (a) 기존 연동 없음 → INSERT 쿼리가 호출됨 (SQL 문자열에 `INSERT INTO post_integrations` 포함, params 순서 확인); (b) 같은 forum_post_id로 활성 연동이 이미 있으면 구현이 하는 동작(스킵/업데이트/예외)을 그대로 검증.
- `addParticipant / removeParticipant / isParticipant / getParticipantCount`: 호출된 SQL이 `forum_participants`를 대상으로 하고 params가 `[forumPostId, userId, ...]` 순서인지; `isParticipant`는 rowCount/rows 기준 boolean 반환 확인.
- `addToWaitlist / isInWaitlist`: 위와 동일 패턴으로 `forum_waitlist`(실제 테이블명 확인).
- 각 테스트는 `vi.fn().mockResolvedValueOnce(...)` 로 쿼리별 응답을 순서대로 지정. SQL 비교는 `expect.stringContaining('INSERT INTO post_integrations')` 처럼 핵심 토큰만 (공백·줄바꿈 정확 비교 금지).
