상태: todo

## 목표 (한 문장)
`npm run lint`가 동작하고, `no-console`(warn)과 `.js` 확장자 누락 import(error)를 검출한다.

## 범위
- 신규: `eslint.config.js` (flat config, ESM)
- 수정: `package.json` — `devDependencies`에 `eslint` 9.x, `globals`, (필요 시) `eslint-plugin-import`; `scripts`에 `"lint": "eslint src scripts"`, `"lint:fix": "eslint src scripts --fix"`
- 건드리지 말 것: `src/**` 소스 코드 일체(이번 태스크는 설정만), `.env*`, `ecosystem*.cjs`, `migrations/`

## 요구 규칙
| 규칙 | 레벨 | 비고 |
|---|---|---|
| `no-console` | **warn** | T-010 완료 후 error로 승격 예정. 예외 파일: `src/config/logger-termux.js`, `scripts/**` (override 블록으로 `off`) |
| 내부 import `.js` 확장자 누락 | **error** | `eslint-plugin-import`의 `import/extensions: ['error','ignorePackages',{js:'always'}]` 권장. flat config 호환이 안 되면 `no-restricted-imports` patterns 등 대안 사용 가능 — 단 `./foo` 와 `../foo` 형태를 잡아야 함 |
| `no-unused-vars` | warn | `argsIgnorePattern: '^_'` |
| `no-undef` | error | `globals.node` 적용 |
| `eqeqeq` | warn | |

- `languageOptions`: `ecmaVersion: 2024`, `sourceType: 'module'`, `globals: globals.node`
- `ignores`: `node_modules/**`, `logs/**`, `readme_src/**`, `*.cjs`(ecosystem 파일)
- Prettier·스타일 규칙(들여쓰기, 세미콜론, 따옴표) **도입 금지** — 기존 코드 스타일 변경 없음

## 단계
1. `npm i -D eslint globals` (+ `eslint-plugin-import` 선택). package-lock.json 갱신 포함.
2. `eslint.config.js` 작성.
3. `npm run lint` 실행 → **error 0** 확인. warn은 허용(`no-console` 약 400건 예상).
   - error가 나오면 규칙 설정 문제인지 실제 위반인지 구분: 실제 `.js` 누락 import가 있다면 **수정하지 말고** 결과 메시지에 파일:줄 목록만 보고 (별도 태스크로 처리).
4. `node scripts/check-docs-drift.mjs` 가 여전히 통과하는지 확인 (`eslint.config.js`는 루트 파일이라 영향 없음).
